SGGS REFLECTIONS — GITHUB PAGES DEPLOYMENT PACKAGE

Contents: static website, original supplied PDF (60,930,613 bytes; 4,131 pages), PDF.js reader, browser-side embedded-text search, individual SEO metadata for HTML pages, Book JSON-LD, robots.txt, sitemap.xml, 404.html, and .nojekyll.

DEPLOY
1. Extract this ZIP. Create a public GitHub repository (e.g. sggsreflections). Upload the CONTENTS of this folder to the repository root (index.html must be at root).
2. In GitHub: Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
3. The project site will appear at https://YOUR-USERNAME.github.io/sggsreflections/ (allow time for deployment).
4. Update canonical URLs, Open Graph URLs, sitemap.xml, and JSON-LD in the HTML/XML files to match the final live URL before launch. For a project URL, include the repository path in canonical URLs.
5. In Google Search Console, add and verify the live property, then submit the sitemap URL. Indexing/ranking is controlled by Google and is not guaranteed.

SEARCH/ACCESSIBILITY
Reader search scans embedded PDF text in the visitor's browser, in page order, and displays up to 30 matching page numbers. Image-only text is not searchable without OCR. The 4,131-page scan can take time and use browser resources. PDF pages themselves are not individually SEO-indexed as HTML; the site’s discoverable HTML pages carry the SEO metadata.
